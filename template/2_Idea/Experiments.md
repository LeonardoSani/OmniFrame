# Experiments

What each experiment establishes about the idea — not how it is run. Configuration lives
in `3_Implementation/Specs.md`; dependency structure lives in `4_Results/Scenario Tree.md`.

E-ids are assigned here once and never reused or renumbered.

### E01 — <name>

- **Establishes** — which hypothesis this bears on, and how.
- **Why worth doing** — what is still unknown without it.
- **Design** — the comparison, in the abstract: what varies, what is held fixed.
- **Expected outcome** — what should happen if the hypothesis holds.
- **Would refute** — the outcome that would count against it. If nothing could, this is
  not an experiment.
