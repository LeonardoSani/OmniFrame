# Where we are

Read this first, at the start of every session. Rewrite it at the end of one.

Every other file holds **state** — what exists, what ran, what the numbers were.
This file holds **intent**: where the work stands in plain words, why the plan looks
the way it does, and what comes next. That is the part no file can reconstruct and
the part you lose over a two-week gap.

Rewritten, never appended. Git holds the history; this holds only the present.
If a section runs past a screen it has stopped being a briefing.

## Now

Where the project stands. What is established, what is still open, what is running.

Claims here cite their evidence — a run record, a card, a section. Before there is a
result, say so plainly rather than describing what you intend to find.

## Why the plan looks like this

The schematic files say *what*; this says *why*. Why
[the scenario tree](4_Results/Scenario_Tree.md) branches where it does, why a
threshold is the number it is, why an experiment is sequenced after another rather
than beside it, why one was dropped.

Without this, the DAG is a diagram nobody can argue with — including you, once you
have forgotten the reasoning that produced it.

## Next

The next one to three moves, in order. Not a backlog: the things that would actually
happen if you sat down now.

## Open

What is undecided, and what would decide it. A question with no route to an answer
belongs here too — say that it has none.
