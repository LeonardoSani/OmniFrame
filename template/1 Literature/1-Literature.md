# Literature

- [[card&outputs_def]] — what a card covers, and which syntheses are commissioned

## Outputs

The syntheses produced from the reading. Files live in `Literature Outputs/`.

## Cards

One per paper, in `Cards/`. Same sections in every card, set by the brief.

## Source

- `PDFs/` — papers as published (gitignored)
- `Papers/<citekey>/` — converted markdown plus extracted images
- `Human encoding/` — the researcher's handwritten notes. Human-only.
