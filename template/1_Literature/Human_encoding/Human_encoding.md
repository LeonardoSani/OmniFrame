# Human encoding

Your handwritten notes, scanned. Organise this page as you like — by theme, by week, by
question — and link a note from it per topic.

Scans go in this folder. A note is `Notes/<name>.md`, embedding the scans it gathers:

```markdown
![](../scan_03.pdf)
![](../IMG_4412.jpg)
```

Notes are not keyed to papers: one often spans several. The agent never reads, cites or
draws claims from them; asked, it may create a note or add embed lines for scans you name.
